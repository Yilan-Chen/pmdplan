# pmdplan 0.1.0

Initial public release.

- Generate planned missing data designs for items and measurement occasions, or create schedules before data collection.
- Apply designs to existing longitudinal datasets across replications, with an optional complete-data comparison.
- Generate complete simulated datasets and prepare or run Mplus analyses using default or custom model syntax.
- Evaluate manual estimates, posterior chains and Mplus output with convergence diagnostics and configurable design-screening criteria.
- Include an empirical affect dataset, worked examples and English reference guides.
